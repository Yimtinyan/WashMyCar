# WashMyCar 交互 Demo v0.4

把准备留在手机，把专注留给洗车。此演示采用本轮双端设计稿的暖白、墨绿与石墨色，优化留白、字阶、文案和完成反馈。

## 打开体验

直接用现代浏览器打开 [index.html](index.html)。它是自包含文件，不需要安装依赖，也不依赖外部字体或运行时CDN。开发预览为 [http://127.0.0.1:5173/dev.html](http://127.0.0.1:5173/dev.html)，需要先启动本机服务。

手机基准：**iPhone 16 Pro Max，440×956**；手表内容区域：**Apple Watch Series 10 46mm，208×248**。桌面并排展示双设备；手机显示完整应用。原有三个独立首页探索仍保留在 [prototypes.html](prototypes.html)，其预览数据没有清除。

## 主要流程

1. **洗车首页**：查看车辆与本次方案，点击步骤编辑药剂、原液量、另加清水、工具、备注；支持添加、删除和排序，洗车地点手动填写。
2. **确认准备**：同瓶多步骤用量先汇总，确认已取用才扣减原液，保存已备流程快照及preparedAt，此时尚不计时；手表步骤确认不会再次扣减。
3. **现场确认**：到达洗车地点后点击手表“开始洗车”，才保存startedAt并开始计时。之前的等待和路程不计入洗车时长；开始后逐步完成、暂停与恢复。完成时自动保存时间、地点、车辆、步骤与药剂汇总。
4. **完成彩蛋**：每次完成随机出现爱车微光、星点或轻浮光环，选择随本次流程保存；自动出现且不设开关，可减少动态效果。
5. **药剂馆**：组合品牌、用途、搜索，新增独立单瓶，检视购入时间、地点、价格及剩余量。
6. **使用履历**：每瓶显示流程备液/单独取用的日期时间、地点及毫升数；手动取用同样可以填写地点。
7. **洗车记录**：完整流程结束后生成记录，显示总时长、有效用时、暂停时长和药剂汇总，并可进入单瓶履历。
8. **设置**：右上角进入外观（跟随系统/浅色/深色）、中文/英文、减少动态效果和演示内完成提醒。清理界面缓存保留库存、标签、历史和当前流程。

## 瓶型与图像

考赫默认外观示意乳白HDPE、灰色肋纹盖；火球默认外观示意透明竖纹PET和银色盖。它们是依据品牌瓶型生成的协调渲染，非原厂包装扫描，不代表所有地区和版本。

详情的“旋转检视”进入可拖动、可用方向键旋转的三维模型；考赫不透明瓶另外提供“查看液位示意”。通用旋盖、喷雾瓶直接使用三维模型。三维液位和进度条按记录余量计算，品牌静态图只展示外观，不伪装成实时液位测量。

银车和两款瓶子素材与本轮Figma稿共用，保存在`src/assets/`。完整手机主页概念：[refinement-home-concept.png](design/refinement-home-concept.png)。设计比较：[设计说明](design/design-notes.md)。

## 数据规则与边界

- 保留原有`washmycar-demo-v2`保存键，并读取迁移v2到v3；已有库存、购买资料和取用历史保留，不自动补入新种子瓶。全新演示包含Fireball HydroShampoo样本。
- 已备流程刷新后仍保持prepared就绪状态；在手表点击“开始洗车”才进入washing，不会再次扣库存。
- “洗车时长”从手表开始按钮算起，包含暂停；“有效用时”排除暂停，两者与暂停时间同时保存。旧版已有startedAt的活跃流程保留原计时，不再备液；没有时间戳的旧进行中流程，恢复时重新开始计时并提示，不编造过去时长。
- 原液从库存中取出的时间标记为“流程备液”，不是精确喷洒时间。确认步骤只推进流程，不重复记账。
- 历史汇总保留完成时的产品和步骤快照，后续编辑当前资料不会篡改历史。
- `localStorage`仅存于当前浏览器/页面来源，文件模式和开发服务各自保存，不跨设备同步。浏览器拒绝保存时会提示。
- 缓存清理只整理`washmycar-ui:`前缀的临时界面缓存，不删除持久化库存和记录。
- 配比、价格、购入和用量均为可编辑示例，使用前核对本瓶标签。地点不申请定位权限；演示提醒不申请系统通知权限；不连接真实Apple Watch，不代表原生通知、云同步或后台服务已经完成。

## 开发与验证

```sh
cd demo
pnpm install
pnpm dev
pnpm build
node --test src/session.test.mjs
```

已有本地依赖时也可以直接运行：

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173
node node_modules/vite/bin/vite.js build
node inline-build.mjs
```

当前应用位于`RefinedApp.jsx`，语义色与响应布局位于`refined.css`；`session.js`独立处理单次扣减、计时和历史快照；`LegacyViews.jsx`保留旧组件供独立探索复用。

2026年11月10日：8项关键账本/计时/迁移测试通过（原6项加prepared相关2项）。原浏览器检查覆盖19项主要路径，检查440×956、390×844、1440×1100及Watch208×248。准备与正式开始分离后，新增2项状态测试已通过；该最后调整尚未完成浏览器增量复验。

本次未提供Browser插件，使用Playwright驱动本机Edge验证。已通过`view_image`对照完整概念和真实截图：布局次序、字阶、暖白/墨绿、开放分隔与主动作保持一致；车型视角采用与Figma共用的新银车，编辑入口和新增记录/设置为功能所需扩展。尚未验证原生设备、Dynamic Type、真实通知或跨设备通信；软件WebGL外观可能与真实GPU不同。

独立文件约6.6MB，包含三张高分辨率示意图及React/Three.js，用于离线评审；真实产品应另做资源压缩、按需加载和原生性能验证。

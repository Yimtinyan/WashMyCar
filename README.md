# WashMyCar 洗车应用

面向个人车主与洗车爱好者的 iPhone 和 Apple Watch 洗车管理应用。

目前处于产品企划阶段，尚未开始应用实现。产品计划连接药剂库存、爱车档案、洗车方案预演、手表现场引导及洗后记录。

## 核心使用流程

管理爱车与药剂 → 编辑方案与计算配比 → 模拟预演与准备 → 手机或手表执行 → 保存记录与改进方案。

## 当前规划边界

首版建议采用本地优先、2D部位示意、单任务执行和单活动药剂计时。Apple Watch的提醒、离线恢复及设备支持范围需经过真机验证。文档已区分已确认方向、设计建议和待验证假设；排期与指标为规划值。

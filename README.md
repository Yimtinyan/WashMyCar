# WashMyCar｜个人洗车方案与现场引导

WashMyCar 是为自己动手洗车的车主设计的 iPhone 与 Apple Watch 应用项目。它围绕一次洗车里的三个实际问题展开：**手里的药剂能用在哪个部位？这次该配多少？洗到这一步，接下来要做什么？**

**项目状态：已有 SwiftUI 原生 v0.1 工程，进入原生编译与界面验证阶段。** 同时保留可离线体验的浏览器 Demo，以及适配 iPhone 16 Pro Max、Apple Watch Series 10 46mm 的可编辑 Figma 精修稿。原生工程已通过 iOS / watchOS 无签名编译和 Mac Catalyst 界面检查，尚未完成签名真机与双端配对验收。

## 使用 Xcode 原生版本

打开 [`native/WashMyCar.xcodeproj`](native/WashMyCar.xcodeproj)，选择 `WashMyCar` 或 `WashMyCarWatch` scheme。工程包含 iPhone、Apple Watch、WidgetKit 扩展和共享业务测试，无第三方依赖。运行与签名步骤见 [原生版说明](native/README.md)，范围与实测结果见 [验证记录](native/verification.md)。

原生版支持方案编排、备液扣库、药剂资料与履历、手机现场引导、WatchConnectivity 传输及手表离线执行代码、历史快照、备注与 JSON 备份恢复。可在 Demo 设置导出备份后导入原生 App。真实手表配对、小组件安装尚待设备验证；HealthKit 与拍摄功能尚未接入。

## 一次洗车，两个使用场景

| 阶段 | 计划中的使用方式 |
| --- | --- |
| 洗车前 · iPhone | 为爱车记录车漆、车衣、轮毂饰面和内饰材质；按品牌与用途整理已有药剂，选择本次要清洁的部位。 |
| 准备方案 · iPhone | 在车辆部位示意图上预演步骤，核对药剂、工具、配比和去除方式。针对材质不明或用法缺失的步骤，在配液前提示。 |
| 洗车中 · Apple Watch | 双手沾水时，抬腕即可查看当前部位、对应药瓶和下一动作。需要停留的步骤按已核实说明提醒；要求立即冲净的步骤直接提示冲洗。 |
| 洗车后 · iPhone | 记录实际用量和操作反馈，更新库存；下次可以复用方案，也可以只调整不合适的一步。 |

## 为什么要按车辆表面建档

同样是“清洗轮毂”，原厂喷漆轮毂和后来重喷过的轮毂，对同一款药剂可能有不同限制。例如 [SONAX Beast 的厂商说明](https://www.sonax.com/en/care-products/beast-wheel-cleaner-500-ml-04332000)明确排除了重喷轮毂。如果车辆档案只记“铝合金轮毂”，应用就会漏掉这个判断条件。

因此，WashMyCar 的方案设计把用法绑定到**具体产品版本、部位、表面材质、保护层和施工方式**。水桶手洗和泡沫壶预洗分别记录配比；厂商没有说明比例含义，或不同资料相互冲突时，保留原文供核对，不向手表下发猜测的用量或倒计时。

第一阶段研究覆盖 **20 个品牌研究对象**，其中 **18 个品牌形成了 62 款具名产品记录**；另整理了 24 类护理用途和 20 种部位与材质建档情形。这些样本用于设计资料库。将某款产品用于现场引导前，仍需核对用户手中瓶装产品的地区版本、标签及车辆表面要求。

下一阶段的重点是选取常用产品，核实一批可以执行的洗车步骤，再用真机验证从 iPhone 准备方案到 Apple Watch 现场提醒的完整流程。

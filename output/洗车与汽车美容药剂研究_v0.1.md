# 洗车与汽车美容药剂研究

版本 v0.1｜第一阶段：品牌、用途、材质与应用数据模型｜整理日期：2026年10月12日

主要资料检索日期：2026年10月11日。对象为个人车主与汽车美容场景；服务于 iPhone 与 Apple Watch 洗车管理应用的产品设计、内容建库和后续研发。

本报告与《洗车药剂品牌与产品资料库_v0.1.xlsx》配套使用。报告解释行业结构、关键差异和应用应该怎么做；表格提供逐产品的用途、材质、用法、资料缺口和官方链接。研究底稿与结构化 JSON 保存于项目 research 目录。

## 1 研究结论与覆盖范围

**应当先建立有证据的药剂知识库，再做方案推荐和手表提醒。** 品牌、药剂名称和用途标签只能帮助用户找到产品；真正决定能否执行的，是具体版本、作用部位、表面材质、已有保护层、施工方式与车辆制造商要求的组合。

本轮纳入20个品牌研究对象，其中18个品牌形成62款具名产品记录。中国本土品牌研究组有6个对象、4个品牌的17款产品；海外研究组有14个品牌、45款产品。保赐利已有品牌归属与业务证据，但本轮未取得可核验的具名产品目录；好顺仍处于主体与目录补证阶段。不能把20个研究对象宣传为20个完整产品库。

研究采用有目的的代表性抽样：覆盖国内常见车用护理品、海外精洗体系、消费者与专业产品线，以及预洗、正洗、去污、内饰、玻璃、保护和修复等不同用途。它不是市场全量普查，也不支持销量、市场份额、性能排名或“中国可以买到”的结论。

对立项最有影响的发现如下。

| 发现 | 对应用的具体影响 |
|---|---|
| 同类药剂的材质边界不同 | “柏油剂”“内饰剂”等类别不能直接产生适用许可；必须匹配具体产品 |
| 部位与材质不是同一字段 | 轮毂还要区分饰面、是否重喷；座椅还要区分皮革、合成革、织物与表面处理 |
| 同一产品有多种施工方式 | 水桶、喷壶、泡沫壶、局部擦拭应分别拥有配比和步骤 |
| 官方资料也可能缺失或矛盾 | 需要待核实、冲突、历史版本等状态；资料不足时不生成确定配比与倒计时 |
| 产品许可还受到车厂和膜厂要求约束 | 建立车辆手册、膜型号、保护层档案；存在明确禁用或未解决冲突时不自动推荐 |
| 清洁、修复和保护是不同任务 | 每次洗车不必去铁、去柏油、抛光、重新镀膜；方案按实际需求选择 |

核心证据例子见第7章。报告中的分类和数据设计属于研究建议；产品本身的声明以逐项官方来源为依据，不代表独立实验室验证。

## 2 研究方法与证据标准

### 2.1 研究对象的边界

纳入用于汽车外部清洁、内饰清洁、污染去除、表面修复、护理保护及相关玻璃清洗系统的化学产品。洗车手套、毛巾、黏土、抛光机、泡沫壶属于关联工具；本轮只在理解施工方式时记录，未建立完整工具目录。燃油添加剂、机油、制动系统维护液、机械维修清洗品不因同品牌销售而自动纳入个人洗车库。

“品牌来源地、总部或法律主体所在地、制造地、中国销售主体、具体SKU销售地区”分别保存。GYEON官网列新加坡总部与韩国工厂；CARPRO的韩国联系地址不能代替其全部法律主体和产品产地证明。中文名称、进口包装或中国工厂地址都不足以单独决定品牌国别。相关证据见品牌表与官网[ GYEON联系信息](https://gyeon.co/contact/)、[CARPRO联系信息](https://carpro.global/contact/)。

### 2.2 不同来源能够证明什么

| 来源 | 可以支持的内容 | 不应据此推断 |
|---|---|---|
| 当前版本包装标签、产品技术单TDS | 指定用途、配比、施工条件、限制；需确认地区和版本 | 不同地区同名产品必然同配方；所有未列材质均兼容 |
| 官方具体产品页 | 产品存在、厂商声明的适用范围及公开用法 | 实测性能、长期耐久、未写明的稀释或停留时间 |
| 安全数据表SDS | 危险性、储存、暴露防护等对应版本信息 | 完整商业配方、所有材质相容性、最佳洗车效果 |
| 官方目录、品牌介绍、正式年报 | 品牌主体、产品线和具名产品 | 某款产品已达到可直接执行的资料完整度 |
| 官方博客、视频、历史技术单 | 特定时期或情境的用法线索 | 覆盖当前标签、跳过地区版本匹配 |

本轮不以经销商介绍、社区经验配比或电商销量替代厂商施工依据。官网访问失败只表示本轮未能取得资料，不表示品牌或产品不存在。来源访问日期与内容修订日期必须分开：2026年读取的2023年技术单仍是2023年版本。

### 2.3 资料成熟度与放行条件

建议正式内容库使用四个阶段：发现条目、资料可读、字段已核对、场景可发布。一个字段核对完成，不意味着整款产品所有用途都能自动执行。

工作簿内“配比有明确依据”仅说明至少一种用法有清楚的数量语义；仍须确认中国在售标签、车辆条件和完整步骤。“参数冲突”表示存在需要处理的矛盾，不表示该产品整体不安全。“资料待复核”允许用户浏览和管理库存，但不足以作为自动施工处方。

正式发布时，每条规则必须保留：来源URL、发行者、地区、产品版本、发布日期或修订号、访问日期、适用字段、原文定位、审核人和审核时间。建议补充来源快照和哈希；本轮已保存摘录与链接，尚未建立全部原网页的完整快照档案。

## 3 先理解药剂在解决什么问题

### 3.1 以污染和目标为起点

| 目标或现象 | 研究中的对应路径 | 需要避免的误判 |
|---|---|---|
| 浮尘、泥沙、普通道路污垢 | 预洗、正洗；轻污条件下可考虑相应免冲洗体系 | 泡沫越厚就越干净；轻污擦拭方法可用于重泥沙 |
| 油性污垢、皮脂、旧护理残留 | 相应脱脂、APC或指定内饰/橡胶清洁 | APC等于任意部位都可用 |
| 铁颗粒、部分制动粉沉积 | 明确支持目标表面的除铁或轮毂产品 | 铁粉剂与所有轮毂剂完全等价 |
| 柏油点、沥青、胶残留 | 相应局部去污剂 | 所有黑点都是柏油；所有去胶剂都适用贴膜 |
| 矿物沉积、水滴痕迹 | 先判断表面残留，再匹配去矿物产品 | 已产生的蚀刻与表面沉积是同一个问题 |
| 旋纹、划痕、氧化外观 | 检查后进入修复评估，而非不断增加清洁强度 | 洗车液可以消除真实划痕；每次洗车都要研磨 |
| 清洁完成后的维护 | 按表面和需求选择蜡、封体、喷冲保护或涂层维护 | 商品名带“镀膜”就等同于独立固化陶瓷涂层 |

从作用机制理解，清洁产品可能借助润湿、分散、乳化或溶解来带走污染；去矿物、除铁和机械研磨又解决不同类型问题。这里的机制解释用于组织信息，不能从产品类别反推完整成分，更不能自动预测混合后的化学反应。配方、浓度、接触时间、工具和表面状态共同影响结果。

例如，CARPRO明确将CeriGlass描述为含氧化铈等研磨体系的玻璃修复产品；它应归入玻璃研磨/前处理，而不是普通玻璃喷雾清洁。[官方产品说明](https://carpro.global/product/ceriglass/)

### 3.2 容易混淆的术语

APC表示通用清洁产品类别，不是“所有材质安全”认证。免冲洗表示省去常规冲洗环节，通常仍使用水；P&S Absolute属于这类产品，而轻污快洗与干燥辅助应另建用途。[Absolute官方页](https://psdetailproducts.com/products/absolute-rinseless-wash)、[Speed Shine官方页](https://www.griotsgarage.com/speed-shine/)

“中性、无酸、陶瓷、石墨烯、镀膜、专业级”等词可记录为产品描述，不能单独决定材质兼容、耐久或操作门槛。专业产品线也不等于禁止个人使用；应按实际设备、步骤、资格和风险要求判断。

## 5 用途分类：从洗净到护理的24类任务

下面是本应用建议使用的用途分类。分类可多选：一款产品可能兼具清洁和保护，但应明确主用途、附带效果以及不同用途的独立步骤。编号对应工作簿“用途分类”。

| 任务组 | 用途分类 | 应用中的理解 |
|---|---|---|
| 基础清洁 | U01泡沫预洗；U02接触正洗；U03免冲洗；U04轻污快洗/干燥辅助 | 按污染与环境选择流程，不把所有清洁方法连续堆叠 |
| 定向去污 | U05通用清洁/脱脂；U06虫渍鸟粪；U07铁污染；U08柏油胶残留；U09矿物沉积；U10黏土润滑 | 必须有需求与适配证据；不是每次洗车必做 |
| 轮毂轮胎 | U11轮毂清洁；U12轮胎橡胶清洁；U13轮胎/塑料/橡胶护理 | 分开清洁与上光，区分胎侧和轮毂，不外推到胎面与制动部件 |
| 玻璃透明件 | U14玻璃日常清洁；U15去油膜/旧涂层；U16驱水保护 | 清洁、研磨前处理与保护不共用一个“玻璃药剂”步骤 |
| 内饰 | U17硬表面；U18皮革/合成革；U19织物/Alcantara | 分类取决于实际表层和部位，屏幕另作精确匹配 |
| 修复与保护 | U20研磨修复；U21洗车附带保护；U22独立保护/维护 | 修复可能改变表面；保护施工存在湿面、干面、即时去除、固化等不同要求 |
| 特殊场景 | U23软顶/透明塑料等专门护理；U24雨刮系统清洗液 | 首版可做资料管理，具备完整说明后再开放自动方案 |

## 6 部位、材质、保护层如何建立对应关系

### 6.1 用“表面结构”描述车辆

建议每个车辆区域至少记录四层：部位、基材或表面材料、现有保护层、当前状态。实际接触的是最外层表面；同一块车门可能是亮光漆，也可能覆有哑光PPF及膜上涂层。仅记录“白色轿车”或“有车衣”不够精确。

| 部位组 | 应进一步区分的材料/表层 | 应询问或导入的状态 |
|---|---|---|
| 车身面板 | 亮光漆、哑光/缎面漆、PPF、改色膜 | 原厂/重喷、膜型号、保护层、破损和边缘状态 |
| 轮毂及金属饰件 | 钢/铝基材；喷漆、电镀、抛光裸铝、阳极氧化等 | 是否重喷、清漆有无、腐蚀、旧保护层 |
| 轮胎、饰条和密封件 | 胎侧橡胶、塑料、涂装塑料、橡胶密封条 | 老化、旧护理剂、允许的外观效果 |
| 玻璃及透明件 | 裸玻璃、内侧隔热膜、外膜、玻璃疏水层、透明塑料 | 前后/内外侧、加热丝、雨刮与摄像头关联 |
| 内饰硬表面 | 硬塑料、vinyl、软触涂层、装饰膜、屏幕表层 | 车厂清洁要求、表层磨损、电子开口 |
| 座椅和软内饰 | 涂饰真皮、特殊皮革、合成革、织物、Alcantara | 打孔、色牢度、胶层、防水处理、底部电子部件 |
| 特殊区域 | 敞篷顶、摄像头、传感器、安全带、操作接触面 | 专门车厂/材料商要求；首版不从大类直接自动推荐 |

材料表不是化学安全白名单。工作簿“部位材质”给出20种建档情形及来源，表示需要区分的对象，不代表每种材料已完成全品牌相容性试验。

### 6.2 三个必须体现的实际例子

第一，轮毂“有喷漆”与“曾经重喷”不能合并。SONAX Beast对应500 mL产品页一方面列多种轮毂饰面，另一方面明确排除重喷轮毂。这要求数据库能够表达正面适用声明、条件和排除项，而不是一个“适用所有轮毂”勾选。[SONAX官方用法](https://www.sonax.com/en/care-products/beast-wheel-cleaner-500-ml-04332000)

第二，Alcantara应保存材料品牌身份，不能与所有翻毛皮统一。清洁剂对Alcantara的声明还要结合材料商的护理要求；材料商明确限制强力溶剂、氯类处理和蒸汽等做法。这里并不推断某种未公开成分的清洁剂必然符合要求。[Alcantara护理指南](https://www.alcantara.com/cleaning-maintenance/)

第三，药剂厂商写适用屏幕，不代表所有车型屏幕都许可。例如Meguiar's Quik Interior Detailer列LCD导航屏幕，而所查Model 3手册对触屏清洁另有明确限制。因此最终匹配必须同时检查具体车辆要求，不能只读药剂瓶。[Meguiar's产品页](https://www.meguiars.com/products/automotive/interior/meguiars-quik-interior-detailer-cleaner-g13616-16oz)、[Model 3对应地区手册](https://www.tesla.com/ownersmanual/model3/en_ie/GUID-65384C1F-86F2-44E8-A8BC-8A12E7E00A40.html)

PPF同样需要膜型号。XPEL的护理页按不同产品系列分别给出要求，因此应用应记录膜品牌与型号，不能只提供“有车衣”一个开关。[XPEL产品护理](https://www.xpel.com/product-care)

## 7 重点核验：十个会影响应用正确性的案例

### 7.1 同为柏油清洁，塑料兼容却不同

Gtechniq W7应用说明明确限制塑料、橡胶、PPF和包膜等；GYEON Tar REDEFINED则明确列喷漆及未喷漆塑料饰条。能得出的结论是两款产品的公开适用声明不同，不能得出“GYEON可以用于一切W7不适用材质”。未列材质仍为未知。[W7官方页](https://gtechniq.com/shop/auto/wash-decon-polish/w7-tar-and-glue-remover/)、[Tar REDEFINED官方页](https://gyeon.co/product/tar-redefined/)

### 7.2 pH中性不等于全材质许可

Koch-Chemie Reactive Rust Remover描述为pH中性，但对抛光铝等敏感表面仍要求预先验证相容性。应用可以记录pH及其测量状态，不能用“中性”直接点亮全部材料的绿色许可。[官方产品页](https://www.koch-chemie.com/en/products/reactive_rust_remover)

### 7.3 一瓶药剂需要多条配比规则

Gentle Snow Foam技术单分别给泡沫喷壶约20 mL加入1 L水、手洗50 mL加入10 L水。两者是不同方法，不能选择一个“默认配比”覆盖所有设备。该厂商还给出与特定产品组合的用法，说明混配若要支持，必须依赖精确的厂家配方；这不能转化为任意混配许可。[官方技术单](https://www.koch-chemie.com/pdf/datasheet/Gentle_Snow_Foam_en.pdf)

### 7.4 到达车身的浓度不是泡沫壶中的浓度

Bilt Hamber Auto-Foam技术单把特定清洁场景中的4%定义为车身触达浓度，而非壶中浓度。设备吸液、混水和设置会影响输出。没有设备测量数据时，应用不能把“1 L壶加40 mL”显示为达到4%车身浓度。[Auto-Foam技术单](https://bilthamber.com/wp-content/uploads/2020/04/auto-foam.pdf)

### 7.5 “30倍”和“几瓶盖”不足以精确计算

标榜B-2192页面标题“30倍”未解释分母；Turtle Wax洗车液按每加仑水加入若干瓶盖描述，所读页面未定义瓶盖毫升数。应用应显示原文并标资料不足，不擅自换成1:30或固定mL。[标榜产品页](https://www.biaobang.cn/blfh/5.html)、[Turtle Wax产品页](https://www.turtlewax.com/products/hybrid-solutions-ceramic-wash-wax-48-fl-oz/)

### 7.6 有明确体积示例时可以计算，但要说清目标

CARPRO Reset给40 mL产品配20 L水，可明确记录为产品:水=1:500。若用户的目标是“装满1,000 mL最终液体”，应计算原液约1.996 mL、水约998.004 mL；若用户输入“已有1,000 mL水”，应加入2 mL原液，最终约1,002 mL。这里是体积近似可加的配液计算示例，不是建议使用1 L小容器替代其规定洗车方式。[Reset官方用法](https://carpro.global/product/reset/)

通用公式：产品:水=1:n，目标最终体积为V时，原液量为V/(n+1)；产品:最终液=1:n时，原液量为V/n。两种语义必须由来源决定。产品:水为1:10且目标最终1 L时，需要约90.91 mL原液；如果原液占最终液的十分之一，则需要100 mL，不能混算。

### 7.7 官方技术单也会有算术矛盾

PURÌFICA所查2023 Rev.3技术单同页写每盖10 mL，又把4盖加入10 L水写作1:400。假定同一瓶盖，实际为40:10,000，即产品:水=1:250。可以确定这组描述不一致，不能确定错误原因，也不能擅自修正厂家的意图。涉及该组合的规则应标为冲突；其他独立且明确的用法应单独审核。[PURÌFICA技术单](https://labocosmetica.com/wp-content/uploads/2022/02/EN_data-sheet-PURIFICA-2.pdf)

### 7.8 不能给所有铁粉剂一个统一倒计时

所查CARPRO IronX页面给3–5分钟，3D BDX页面给1–2分钟。相同功能没有相同时长保证；区间还不是最佳值或最大安全值的同义词。手表只能展示已核对的对应产品时间逻辑，不能取全品类平均值。[IronX用法](https://carpro.global/product/ironx/)、[BDX用法](https://3dproducts.com/products/3d-bdx-iron-remover-brake-dust-cleaner)

### 7.9 同名、同系列、同官网也可能有版本问题

三和泡沫清洁剂存在不同页面规格；SONAX Alcantara清洁的气雾版不能与非气雾版直接合并；W7英美页面的去除步骤也有差异。产品识别至少包括品牌、官方名称、型号、销售市场、包装形式与配方修订版本。[三和当前样本页](https://www.sanvo.com/product/detail-754.html)、[另一同名页面](https://www.sanvo.com/product/detail-371.html)、[W7英国说明](https://www.gtechniq.co.uk/shop/auto/wash-decon/w7-tar-and-glue-remover/)

### 7.10 计时并非总是“等几分钟”

GYEON WetCoat按湿面分区使用后立即冲洗；SOFT99 Glaco BLAVE要求施工后立即擦净；另有产品要求适当干燥或固化。CARPRO Spotless 2.0同页玻璃章节与警示段的停留措辞也需进一步澄清。应用应区分立即去除、停留区间、状态观察、固化等待与禁止干燥；有冲突时不自动生成计时。[WetCoat](https://gyeon.co/product/wetcoat/)、[Glaco BLAVE](https://www.glaco.jp/english/products/glaco_blave.html)、[Spotless 2.0](https://carpro.global/product/spotless/)

## 8 如何把资料变成洗车方案

### 8.1 方案生成顺序

建议先读取车辆区域和材料，再让用户选择本次目标与污染情况，随后从用户库存中筛选适配产品。最后生成有条件的步骤、配液清单和工具清单。识别不明时允许用户拍照、补标签或手动标记“待确认”；不能靠照片推断透明涂层、配方或特种材料的全部信息。

每一步都应说明“为何需要”，并把基础清洁与按需去污分开。去铁、去柏油、去水垢并非固定的每周步骤；品牌提出的多pH流程也只是特定产品体系，不自动成为所有车辆的标准流程。

### 8.2 四种用户情境

| 场景 | 方案应做什么 | 应暂停自动匹配的情况 |
|---|---|---|
| 亮光漆日常维护 | 根据污垢和设备选择基础洗车；污染去除、护理作为条件分支 | 漆面是否重喷、已用药剂版本或现有涂层不明且影响兼容 |
| 全车PPF或哑光膜 | 以膜型号、外观和已有涂层为过滤条件；优先有明确支持的样本 | 只有“车漆安全”声明；膜厂与药剂说明相冲突 |
| 内饰日常清洁 | 先分硬表面、皮革/合成革、织物、屏幕；各自使用工具与方法 | 座椅材质仅写“皮”、屏幕无车厂用法、顶棚不明结构 |
| 局部重污染或美容修复 | 先识别污染还是损伤，局部方案独立评估 | 未知表层、持续清洁无效、需机械研磨但缺工具和施工依据 |

### 8.3 不模拟无法验证的化学结果

首版“模拟洗车”适合呈现步骤顺序、作用区域、准备量、预计操作时间、工具切换和证据缺口。时间可以由用户实际记录逐步校准，并注明估算；不要模拟出精确的去污率、划痕修复量或涂层寿命。

跨品牌产品可以出现在同一套方案的不同步骤，但这不等于可在同一容器混合。首版建议仅支持单产品加水及各步骤之间的规定去除/冲洗；若未来支持厂商明确的组合配方，应采用经过审核的具名配方，不开放自由混合并预测安全性。

## 9 给研发和内容团队的数据设计

### 9.1 需要独立保存的对象

| 对象 | 核心字段 | 原因 |
|---|---|---|
| 品牌与主体 | 名称、别名、所有者/主体、来源证据、生产和市场信息 | 避免国别、代理商、制造商混在一个字段 |
| 产品家族与具体版本 | 产品名、型号、条码、市场、容量、包装形式、修订号 | 同名不同版本不串用参数；容量规格与配方版本可关联而不混同 |
| 用途与施工规则 | 任务、部位、方法、工具、适用/禁用/未知、条件 | 一款产品可有多条用法 |
| 配液规则 | 原文、比例方向、量纲、范围、用途、目标体积语义、设备校准 | 防止水桶与泡沫壶混用；避免倍数误算 |
| 时间与去除规则 | 起算点、最短/最长、推荐范围、观察条件、去除方式、温度约束 | 区分反应停留、擦除、冲洗、干燥和固化 |
| 车辆表面 | 部位、材料、保护层、状态、OEM/膜厂资料 | 支持实际车辆的匹配与排除 |
| 来源与审核记录 | URL、文档版本、字段定位、核验结果、复核时间 | 更新产品时知道哪些方案受影响 |
| 用户库存与配制批次 | 产品版本、原液库存、已配液体、开封/配制记录、容器标签 | 浓缩原液和工作液分别管理，避免重复扣减 |
| 方案与执行会话 | 条件分支、产品版本、规则快照、当前执行设备、操作事件 | 手表离线时仍使用确定版本；避免资料更新改写进行中的步骤 |

### 9.2 兼容性状态与处理规则

建议兼容性至少分为“来源明确支持、条件支持、来源明确排除、未知、来源冲突”。这些是证据状态，不是独立安全评级。用户手动说明可以补充车辆事实，但不应直接改写已核实的厂商禁用规则。

匹配时先检查确切产品版本、方法和车辆区域，再合并药剂、车辆、膜或涂层的约束。若存在明确排除则阻止自动推荐；冲突进入人工复核；未知可浏览、收藏、管理库存，但不得被显示为已验证适配。只有适用依据和所需执行字段完整的具体场景才进入发布队列。

对于环境条件，无法测得表面温度时就保存“未知”，不能用天气气温当作面板温度。浓度范围、停留范围也不应因用户选择“重污”而无限外推。

### 9.3 Apple Watch应该显示什么

洗车前在手机完成车辆确认、产品版本匹配和配液准备；洗车时手表呈现一个明确行动。建议最小卡片字段为：步骤、部位、产品短名/容器标识、已经核准的用量或使用状态、关键限制、去除动作和计时状态。

例如“左前轮毂｜已确认的轮毂剂｜按当前规则施工｜完成后充分冲净”，应绑定具体样本、车辆饰面和会话规则。界面示例本身不能替代核准用法。立即冲洗型产品应突出“立即冲净”，而不是给一个人为等待倒计时；材料或配比冲突应在准备阶段解决，现场不让用户猜。

时间区间可以显示最早检查点与来源规定上限，但只有在来源确实赋予这些含义时才这样建模。厂商写“3–5分钟”而未说明边界作用时，保留区间并审核呈现方式；绝不能宣称5分钟在所有环境下安全。用户观察到即将干燥时，不能为了等待计时结束而继续停留。

上述是内容交互要求；watchOS通知、离线同步、水锁和执行设备所有权等技术约束沿用已交付产品企划。内容库不应假设手表能够始终亮屏、可靠测量表面温度或自动识别药剂反应完成。

## 10 第一版内容库的落地顺序

### 10.1 先做可用场景，再扩大品牌数量

建议从用户实际拥有或计划使用的产品中选择15–20款作为试点，覆盖普通正洗、预洗、轮毂、玻璃、内饰和基础保护。这里是建议的工作范围，不是已完成的发布数量。每款至少核对一种常用场景，达到可以审阅、可以解释、可以复现计算的程度。

国内产品优先补中文背标、型号/条码、厂家说明与生产主体；海外产品优先补中国销售版本与海外技术资料的对应关系。先得到“这瓶是什么、如何用、哪里不能用”，再增加更多品牌。

| 工作包 | 具体交付 | 完成条件 |
|---|---|---|
| 产品身份核对 | 背标、条码、容量、地区、修订版、主体 | 能唯一定位用户手中的瓶装产品，不靠中文简称猜测 |
| 施工字段核对 | 每用途的配比、工具、条件、去除方法及时间 | 来源可定位；无冲突或已得到可信解释 |
| 材料规则核对 | 药剂声明与车型/膜/材料商要求 | 同时保留支持、排除、条件和未知 |
| 内容审核与测试 | 字段校验、计算用例、手机与手表文案 | 所有数值有依据；没有把未知显示成允许 |
| 小规模验证 | 经确认条件下的流程可用性记录 | 验证操作与提醒是否清楚；不据少量体验宣称广泛化学兼容 |
| 扩充与维护 | 新SKU、失效链接、版本变更、停产处理 | 历史会话可追溯；进行中方案不被静默改写 |

### 10.2 下一轮最值得补的内容

第一优先级是现有62款样本的资料完整度，尤其中国产品标签、P&S和Meguiar's专业品的当前配比依据、W6与PRÌMUS的版本映射、PURÌFICA冲突澄清。其次是保赐利、好顺具名目录和可执行参数。

类别补充应优先考虑当前薄弱的专用皮革、哑光/车衣维护、涂层前处理、敞篷软顶和独立固化涂层。品牌扩展候选可包括Optimum、RUPES、Menzerna及专门皮革护理体系；这些是后续研究方向，不计入本轮20个品牌对象或62款主样本，也不表示当前所有产品参数已验证。

价格、单位用量成本、中国渠道与假货识别应作为后续单独研究。成本须依准确配比、包装容量和可靠价格计算；没有用量证据时，不能给出貌似精确的“每次洗车成本”。

## 11 下游验收清单

以下是正式内容库与应用实现应满足的验收场景；不是本轮已执行的应用测试。

| 场景 | 预期行为 |
|---|---|
| 未定义两端的1:500或“30倍” | 保存原文，自动计算不可用，并说明缺少什么 |
| 产品:水=1:10，目标最终1 L | 计算约90.91 mL原液与909.09 mL水；明确舍入与工具精度 |
| 已有1 L水且产品:水=1:10 | 加100 mL原液；最终体积约1.1 L，不误写为1 L |
| Auto-Foam只有目标PIR，没有设备校准 | 不输出宣称准确的壶内配方 |
| 车身有PPF而选择W7对应版本 | 根据明确排除阻止自动推荐；局部试用不撤销禁用 |
| 轮毂标记为重喷并选择Beast对应SKU | 命中明确排除，不因“喷漆轮毂支持”而通过 |
| 屏幕产品声明与具体车厂要求冲突 | 进入复核，不静默采用某一来源 |
| PURÌFICA瓶盖示例与比例不一致 | 冲突字段不可自动计算；不否定产品全部其他用法 |
| WetCoat等要求立即去除 | 显示去除行动，不生成任意等待时间 |
| 同名不同地区/配方版本 | 保持独立记录；不按名称直接合并 |
| 新版说明替换旧版 | 标记受影响规则与后续方案；已开始会话继续保留原快照并处理必要中止通知 |

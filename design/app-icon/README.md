## 设计依据

图标依据仓库 [产品目标](../../output/洗车应用产品企划与需求说明_v1.0.md) 第 1–5 章、[GitHub 项目描述](https://github.com/Yimtinyan/WashMyCar/blob/codex/native-xcode/README.md)，以及现有 [界面色彩](../../demo/design/design-notes.md) 与 [双端设计简报](../figma/brief.md) 绘制。

WashMyCar 面向自己动手洗车的车主，连接药剂准备、车辆护理方案、腕上现场引导和长期记录。图标把这些能力收束为“悉心护理自己的车”：水滴表达清洁，水滴中的一道留白形成车顶、风挡和引擎盖的连续轮廓，整体保持一个明确的主符号。

深墨绿延续界面 `#163E3C` 的色彩方向，铂银与珠白呼应项目中的银色爱车及 `#F7F8F5` 浅色底。生成图像含轻微色调与材质变化，色值用于指导而非逐像素指定。简洁轮廓、大面积留白与轻微缎面层次共同营造克制的高奢感。

## 检查

- 通过 `sips` 核对交付 PNG 为 1024 × 1024、RGB、无透明通道。
- 目视检查原图及 60 / 40 像素缩略图：水滴主体和车顶留白可辨，外沿与切线清晰。
- 检查无文字、水印、额外边框或预制圆角；小尺寸检查属于图像预览。
- 本次只新增图标资产、生成提示词和文档，不涉及业务逻辑与用户资料。

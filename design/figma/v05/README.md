## 编辑与恢复记录

`sync.mjs` 首次导入 10 个手机画板并创建既有页面入口；最终原型连接因参数名错误在写入前被拒绝。`finish-sync.mjs` 使用已有节点完成连接，没有重复导入，再新增第二瓶快照及 Watch 状态。两个药剂分别打开自己的快照。

导出发现继承的旧标题与新标题重叠，`visual-fix.mjs` 隐藏重复旧标题并修正设置行间距；随后重新导出。隐藏的旧标题不是可见内容。`patch-result.json`、`append-result.json`、`wire-result.json` 和 `visual-fix-result.json` 保留实际修改 ID。

这些脚本是本次操作记录，不应盲目重新执行；尤其不要再次运行 `finish-sync.mjs` 创建重复画板。后续先读取当前画布，使用已有节点 ID 定向更新。脚本不会保存或公开本机连接口令。

设计稿表达 UI 与状态，不证明真实手表传输、HealthKit 或系统安装能力已完成。实现边界见 [本轮落地说明](../../personal-reliability-v05.md)。

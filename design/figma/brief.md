# WashMyCar 双端 UI UE Demo

设计依据：用户提供的《NIO 蔚来设计风格研究与首页UI落地指南》。采用任务优先、语义留白、精确对齐、少量强调色；使用文档建议的柔白/青灰/深青色系。文档中的颜色与尺寸不是 NIO 官方规范；不使用 NIO 标识或专属字体。

交付范围：原生可编辑 Figma Design 文件、iPhone 核心流程及异常状态、Apple Watch 接收/逐步确认/暂停/完成/未接收状态、共享组件与语义变量、主要页面跳转。不是把原网页截图贴入手机框。

手机负责出发前的流程、药剂、原液量/清水量、工具与购买信息管理；手表仅现场显示和确认。计划不扣库存，确认取用才扣一次。药剂数据、购入记录、库存、用量均为演示样本。品牌参数不从界面风格推断。

画板基准：iPhone 393×852逻辑单位；Watch198×242。手机主操作区不小于44，手表主确认44。中文 Figma 使用可用的 Noto Sans SC；通用数字/拉丁保留 SF Pro 设计映射，大号余量 `number` 角色使用 Inter Regular，避免当前环境中 SF Pro 字体或字形度量导致的余量消失。原生开发仍映射系统中文/SF并单独验证；不宣称已经完成真机 Dynamic Type 或手表连通测试。

2026年11月9日，已通过本地开发插件在真实 Figma 桌面修正三个余量文字节点，并导出药剂详情与手表预洗页面作视觉检查。修正采用 Inter Regular、38字号、44行高和固定文字框；仅代表这几个图层与页面的检查通过，不扩展为所有 Watch 状态已完成审查。

结构采用“出发首页 + 有序作业单 + 私家药剂馆”：首页只有当前任务和主操作；编排聚焦列表；库存开放式陈列；检视页让药剂与剩余量成为焦点，购买信息为安静的三行标签。

基础色：Canvas #F8FAF9 / Surface #FFFFFF / SurfaceAlt #F0F5F4 / TextPrimary #1D3137 / TextSecondary #586A71 / ActionPrimary #116A70 / Selected #E3F0F0 / Border #DEE7E7。Watch采用深色专用语义色以保持可读性。

使用 typography、design-system、ui-review 的适用原则；ui-prototyping用于比较信息组织方向，其Swift预览工作流与swiftui-pro的代码审查留待原生实现。本阶段没有Swift代码，不为了使用技能额外生成未验证的原生工程。

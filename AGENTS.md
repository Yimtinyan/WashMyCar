# Project workflow

The user requests that each completed discussion/change round be committed and pushed to the existing GitHub repository. Verify appropriate checks, review staged paths, exclude credentials, runtime data and dependencies, commit and push without asking again. Verify the remote commit before claiming upload success. Do not claim deployment or native-device integration from a browser demo.

Preserve existing inventory, purchase metadata, usage ledger and wash history across migrations. Preparing supplies debits once; starting the wash starts the timer; step confirmations never debit again. Finished records are snapshots; user notes remain editable. Completion celebrations are automatic and must have no exposed preference switch; respect reduced-motion accessibility.
